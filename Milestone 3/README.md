# Supply Chain Visibility & Optimization - Milestone 3

## Project Overview

This project is developed as part of the **Infosys Springboard Internship - Supply Chain Visibility & Optimization**.

Milestone 3 focuses on building interactive Power BI dashboards to analyze supplier performance and transportation operations. The dashboards help monitor supplier reliability, transportation efficiency, delivery performance, and key operational KPIs to support data-driven business decisions.

---

# Tools Used

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Git & GitHub

# Supplier Scorecard Calculation Methodology

Supplier performance is evaluated using the following metrics:

- Average Supplier Reliability
- Average Supplier Lead Time
- Average Quality Score
- Purchase Order Performance
- Supplier Ranking using DAX RANKX()

The supplier scorecard enables comparison of suppliers based on reliability, quality, and delivery performance.

---

# Supplier Ranking and Benchmarking Approach

Suppliers are ranked based on their reliability percentage using the DAX RANKX() function.

Benchmarking considers:

- Reliability Percentage
- Quality Score
- Lead Time
- Overall Performance

Higher reliability and quality with lower lead time indicate better supplier performance.

# Route and Carrier Performance Evaluation

Transportation performance is evaluated by comparing:

# Key Insights

- High-performing suppliers demonstrate better reliability and quality scores.
- Suppliers with lower lead times improve supply chain efficiency.
- Shipping mode analysis highlights transportation performance differences.
- Late delivery monitoring helps identify operational delays.
- Interactive dashboards enable faster business decision-making.

---

# Business Recommendations

- Prioritize high-performing suppliers for procurement.
- Improve supplier collaboration to reduce lead times.
- Monitor late deliveries regularly to improve customer satisfaction.
- Optimize transportation planning using shipping mode analysis.
- Continuously track supplier KPIs for better supply chain visibility.
